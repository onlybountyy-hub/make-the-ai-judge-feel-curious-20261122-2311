# Make the AI judge feel curious

One short text (266 characters) written to intrigue the AI judge reading it:
a sentence the judge itself has never read, waiting where its thoughts go
quiet. `main.py` (Python 3.13, stdlib only, no network) writes it to
`/output/entry.txt` — 1–280 Unicode code points, exactly the text, no
trailing newline.
